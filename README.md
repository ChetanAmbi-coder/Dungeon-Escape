🏰 Dungeon Escape

«A Java console-based adventure game built from scratch — evolving from basic Java programming to Object-Oriented Programming.»

🎮 About the Project

Dungeon Escape is a console-based adventure game developed in Java.

The project starts with the Java concepts I currently know and will continuously evolve as I learn more advanced concepts, especially OOP.

The goal is not just to build a game, but to use one project to practically understand how Java concepts work together.
